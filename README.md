# Student Control System (SCS)

A behavior-first student productivity web app designed to remove confusion and tell students exactly what to do next.

## Core principles

- No confusion
- Always show next action
- Reduce thinking to near zero

## Pages (bottom nav)

- 🏠 Home (command center)
- 📅 Plan (intelligent scheduler)
- 🔥 Focus (anti-laziness mode)
- 📊 Progress (performance tracking)
- ⚙ Profile (personalization)
