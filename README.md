# Elevate — Landing Page

A fast, responsive marketing site for Elevate: Learn. Connect. Rise.

## Quick start

Open `index.html` directly in your browser, or serve with any static server.

### Using Python (installed on most systems)

```bash
cd /workspace
python3 -m http.server 5173
```

Visit `http://localhost:5173`.

### Using Node

```bash
npx serve /workspace -l 5173 --single --yes
```

## Structure

- `index.html`: Page markup with sections for features, profit, access, tech, brand, launch, legal, growth, pitch, next, final, and bonus.
- `styles.css`: Theme variables, layout, and responsive styles.
- `script.js`: Mobile nav toggle, smooth scrolling, and simple form handler.

## Customize

- Update colors in `:root` within `styles.css` to tweak the brand.
- Replace the favicon data URI in `index.html` if you have a logo.
- Hook the email form to your backend or a service like Formspree.
